How to export
Schwab.com (recommended)
  1. Log in → Accounts → History → Transactions
  2. Pick the account, filter All transactions, set a date range
  3. Export → CSV. Keep exports ≲1,500 rows (≈ a quarter for active traders) — larger exports can download empty.
Includes fees, expirations & assignments; no execution times.
thinkorswim (adds exact times)
  1. Monitor → Account Statement, set the date range
  2. Menu (top-right) → Export to file → CSV
Fill-level times for hold-time & hour-of-day stats; no fees. Import both for the best data.
