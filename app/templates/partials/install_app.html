Install as an app (free)
Opens full-screen from your home screen / dock, with its own icon. No app store, nothing to pay.
Installed ✓ (you're running the app)
iPhone / iPad (Safari)
Open this site in Safari → Share (square with arrow) → Add to Home Screen → Add.
Android (Chrome)
Menu ⋮ → Install app (or “Add to Home screen”) → Install. Or tap the button above if it appears.
Desktop (Chrome / Edge)
Click the install icon at the right end of the address bar (or menu → Cast, save and share / Apps → Install Trading Journal).
You still sign in as usual; the app only caches its icons and styles, never your trades, so it needs a connection to show data.
