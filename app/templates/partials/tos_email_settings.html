1 · Turn on fill emails in thinkorswim (desktop)
  1. Setup (gear, top right) › Application Settings › Notifications.
  2. Under Send email to, enter your Gmail address › Get confirmation code › enter the code from the email.
  3. Under Notify about, select Working orders filling and tick Send Email.
  4. Apply settings. Emails come from {{ t.sender }}. (thinkorswim manual)
2 · Install the Gmail script (free, runs in your Google account)
  1. {% if t.has_token %}Copy the script (button on the right).{% else %}Click Create ingest token above, then copy the script.{% endif %}
  2. Open script.google.com › New project, signed in with the Gmail account that receives the fill emails.
  3. Replace everything in Code.gs with the script › Save (name it e.g. “Trading Journal fills”).
  4. In the function menu pick setup › Run (once).
  5. Authorize: Review permissions › your account › Advanced › Go to project (unsafe) (it's your own script) › Allow (Gmail + external requests).
  6. Done: it checks every minute. Each forwarded fill email is labelled Trading Journal/Fills, marked read and archived. An email whose upload fails stays in the inbox, unlabelled, and is retried. Check runs under Executions.
3 · Optional: hide fill emails instantly (Gmail filter)
  1. In Gmail, click the search options icon (sliders) in the search bar.
  2. From: {{ t.sender }} › Create filter.
  3. Tick Skip the Inbox (Archive it) and Apply the label › Trading Journal/Fills (exists after setup runs; or New label… “Fills” nested under “Trading Journal”) › Create filter.
  4. The script searches by sender, not the inbox, so filtered emails are still forwarded. (This also files thinkorswim's other alerts.)

If you regenerate the token, paste the updated script into the same project (no need to run setup again). Anyone with the token can add fills to this journal: keep the script private.
